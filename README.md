SETUP

1. Run install.bat
2. Open config.json
3. Paste your bot token
4. Set your verified role ID
5. Add your image URLs
6. Run start.bat

DISCORD DEVELOPER PORTAL SETTINGS

✔ SERVER MEMBERS INTENT
✔ MESSAGE CONTENT INTENT

(IMPORTANT — bot will NOT work without these enabled)

COMMANDS

!verifypanel

PERMISSIONS

• Manage Roles
• Send Messages
• Embed Links
• View Channels

IMPORTANT

The bot role MUST be above the verification role in Discord.
